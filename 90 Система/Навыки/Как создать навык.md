# Как создать навык

Навык — это заметка-инструкция в папке `90 Система/Навыки/`. Имя файла — имя
команды: `финансы.md` → вызывается в чате как `/финансы`.

```markdown
---
description: Одной строкой — что делает навык
---
Пошаговая инструкция для Джарвиса.
$ARGUMENTS — сюда подставится текст после команды.
```

Проще всего попросить: «Джарвис, сделай навык, который каждый вечер
подводит мои траты». Он создаст файл сам.

Встроенные навыки (общие с Claude Code на компьютере) лежат в скрытой
папке `.claude/commands/`.
