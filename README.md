# ◉ Джарвис — личный ИИ-ассистент в Obsidian

Хранилище Obsidian со встроенным ИИ-ассистентом **Джарвисом** на базе Claude.
**Работает на iPhone** (и на компьютере), без терминала и без серверов.

Что умеет Джарвис:

- **Знает то же, что и ты.** Он читает всё хранилище и ведёт память о тебе в `10 Я/`: профиль, цели, люди, решения.
- **Полностью управляет хранилищем.** Создаёт и правит заметки, раскладывает «Входящие», ведёт дневник, связывает заметки ссылками, архивирует, ставит плагины.
- **Улучшает себя.** Учится на твоих 👍/👎 и поправках, записывает уроки, создаёт себе новые навыки и правит собственные правила. Каждое изменение записывается в журнал и сохраняется в резервной копии.
- **Ведёт себя как Джарвис.** Утром готовит брифинг, ищет в интернете, может отвечать голосом, вызывается через Siri.
- **Помогает решать и оптимизировать.** Разбирает решения с опорой на твои ценности, делает недельные обзоры, находит паттерны, предлагает эксперименты.

## 📱 Установка на iPhone (5 минут)

Понадобится:
- приложение **Obsidian** из App Store (бесплатно);
- **API-ключ Anthropic**: [console.anthropic.com](https://console.anthropic.com/settings/keys) → API Keys → Create Key. Пополни баланс, хватит $5–10.
  Подписка Claude Pro/Max сюда не подходит: API оплачивается отдельно, за фактическое использование.

Шаги:

1. **Скачай хранилище.** В Safari открой этот репозиторий на GitHub → зелёная кнопка **Code** → **Download ZIP**.
2. **Распакуй и перенеси.** В приложении «Файлы» нажми на ZIP, чтобы распаковать. Переименуй папку в `AI_Obsidian` и перемести её в «На iPhone → Obsidian» (или «iCloud Drive → Obsidian», если нужна синхронизация с Mac).
3. **Открой в Obsidian.** Obsidian → «Open folder as vault» → выбери `AI_Obsidian`.
4. **Включи плагины.** Obsidian спросит, доверяешь ли ты этому хранилищу. Нажми **Trust author and enable plugins**. Если не спросил: Настройки → Сторонние плагины → «Включить сторонние плагины».
5. **Мастер Джарвиса** откроется сам. Укажи, как к тебе обращаться, вставь API-ключ и нажми **«Запустить»**. Мастер:
   - создаст недостающую структуру хранилища;
   - установит плагины Dataview, Tasks и Calendar;
   - начнёт знакомство (`/interview`). Чем подробнее ответишь, тем умнее будет Джарвис.

Чат открывается значком 🤖 (на iPhone: меню ☰ слева) или командой «Джарвис: Открыть чат».

### Уже есть своё хранилище?

Скопируй 3 файла из `.jarvis/plugin/dist/` (`main.js`, `manifest.json`, `styles.css`) в папку
`<твоё хранилище>/.obsidian/plugins/jarvis/`. Проще сделать это на компьютере через iCloud: папки с точкой скрыты в «Файлах» iOS.
Затем включи плагин «Джарвис» в настройках. Мастер сам создаст недостающую структуру, а твои существующие заметки не трогаются.

## 💬 Как пользоваться

Пиши или диктуй обычными словами (🎤 на клавиатуре iOS):

> «Запиши, что у Саши день рождения 12 марта»
> «Что я решил насчёт отпуска?»
> «Разложи входящие»
> «Составь план на неделю, учитывая что в среду я в командировке»
> «Сделай навык, который вечером подводит мои траты»

Быстрые кнопки над полем ввода: **Брифинг · Входящие · День · Неделя · Улучшись**.

| Навык | Что делает |
|---|---|
| `/brief` | Утренний брифинг: погода, 3 главных дела, сроки, люди, решения на проверку |
| `/interview` | Знакомство: заполняет память о тебе |
| `/daily` | План дня утром, итоги вечером |
| `/inbox` | Разбор «Входящих» по проектам, сферам и знаниям |
| `/weekly` | Недельный обзор, паттерны, план и рефлексия Джарвиса о себе |
| `/decide <вопрос>` | Разбор решения: варианты, риски, рекомендация, запись в журнал |
| `/remember <факт>` | Запомнить факт |
| `/audit` | Три изменения, которые дадут больше всего пользы, и чистка хранилища |
| `/ask <вопрос>` | Ответ строго по заметкам, со ссылками |
| `/improve` | Самоулучшение: отзывы и диалоги превращаются в уроки, навыки и правила |

Джарвис может придумывать и **новые навыки**: они появляются в `90 Система/Навыки/`.

### 🎙 «Привет, Siri, Джарвис»

В приложении **Команды** создай команду «Джарвис» из трёх действий:
1. **Продиктовать текст** (язык: русский).
2. **Кодировать URL** → вход: «Продиктованный текст».
3. **Открыть URL**: `obsidian://jarvis?q=` + «Кодированный URL».

Теперь можно сказать «Привет, Siri, Джарвис» и сразу продиктовать вопрос.
Для быстрой записи мысли без ИИ используй `obsidian://jarvis?capture=` + текст: заметка сразу попадёт во «Входящие».
Команду можно вынести на экран «Домой», на кнопку действия iPhone или в виджет.

Озвучка ответов включается значком 🔊 в чате.

## 🧠 Как Джарвис улучшает себя

```
твои 👍/👎 и поправки ─┐
диалоги (90 Система/Диалоги) ─┼─► /improve и /weekly ─► уроки в «Джарвис.md»
повторяющиеся просьбы ─┘                          ├─► новые навыки
                                                   └─► правки CLAUDE.md
           каждое изменение → «Журнал улучшений.md» + резервная копия в .jarvis/backups/
```

- `90 Система/Джарвис.md` — его характер и раздел «Уроки». Его можно править и тебе.
- `90 Система/Навыки/` — навыки, которые он создал сам.
- `90 Система/Журнал улучшений.md` — что он в себе изменил и зачем.
- `90 Система/Обратная связь.md` — твои оценки.

Хочешь одобрять каждое изменение? Включи в настройках «Спрашивать перед изменением своих правил».

## 🗂 Структура

```
Главная.md            ← панель: фокус, задачи на сегодня, проекты, входящие
00 Входящие/          ← всё подряд, Джарвис разберёт
01 Дневник/           ← дни и недели
02 Проекты/           ← дела с результатом и сроком
03 Сферы/             ← здоровье, финансы, работа, отношения, развитие
04 Знания/            ← справочник, конспекты
05 Архив/             ← завершённое (Джарвис ничего не удаляет)
10 Я/                 ← ПАМЯТЬ о тебе
90 Шаблоны/           ← шаблоны заметок
90 Система/           ← сам Джарвис: личность, навыки, отзывы, журнал, диалоги
CLAUDE.md             ← главные правила (общие для плагина и Claude Code)
.claude/commands/     ← встроенные навыки (общие с Claude Code)
.jarvis/plugin/       ← исходный код плагина
```

## 💻 На компьютере и в облаке (по желанию)

Та же память и те же правила работают в **Claude Code**:

```bash
cd AI_Obsidian && claude      # затем /brief, /inbox, /improve …
```

Чтобы iPhone, компьютер и [claude.ai/code](https://claude.ai/code) видели одни и те же заметки, синхронизируй хранилище с GitHub через плагин **Obsidian Git**. Его можно поставить из настроек Джарвиса.

## 💰 Стоимость

Ты платишь Anthropic только за использование. Повседневный запрос обычно стоит несколько центов.
Неизменная часть (правила и память) кэшируется, и повторные запросы заметно дешевле.
Расход виден в строке под чатом: ↑ сколько отправлено · кэш · ↓ сколько получено.

- **Opus 5.5** — самый умный, стоит по умолчанию.
- **Sonnet 5.5** — примерно в 2 раза дешевле.
- **Haiku 5.5** — очень дешёвый, подходит для простых дел.

Модель и «глубину размышлений» можно сменить в настройках.

## ⚠️ Приватность

- Держи репозиторий на GitHub **приватным**: в хранилище личные данные.
- API-ключ хранится только на устройстве (`.obsidian/plugins/jarvis/data.json`) и исключён из git.
- Джарвис отказывается записывать пароли, номера карт и коды.
- Текст заметок, которые Джарвис читает, отправляется в Claude через API Anthropic.

## 🛠 Разработка плагина

```bash
cd .jarvis/plugin
npm install
npm run check                 # проверка типов
node build.mjs --install      # сборка → dist/ и .obsidian/plugins/jarvis/
```

Стартовая структура (память, шаблоны, навыки) встраивается в `main.js` при сборке.
Поэтому после правки шаблонов пересобери плагин.
