# AI_Obsidian — личный ИИ-ассистент в Obsidian

Хранилище Obsidian, в котором «мозгом» работает **Claude Code**. Ассистент:

- **знает то же, что и ты**: читает все заметки и ведёт долговременную память о тебе в `10 Я/`;
- **управляет хранилищем**: создаёт заметки по шаблонам, разбирает входящие, связывает ссылками, архивирует;
- **помогает принимать решения**: опирается на твои ценности, цели и журнал прошлых решений;
- **оптимизирует жизнь**: находит паттерны в дневнике, проводит недельные обзоры и аудиты, предлагает эксперименты.

Ассистент не обучается в техническом смысле. Всё, что он о тебе «знает», хранится
в обычных Markdown-файлах, которые ты можешь читать и править. Перед каждой задачей
он перечитывает их по правилам из [`CLAUDE.md`](CLAUDE.md).

## Как это устроено

```
AI_Obsidian/
├── CLAUDE.md               ← «конституция» ассистента: роль, правила, структура
├── .claude/
│   ├── commands/           ← сценарии: /interview, /daily, /weekly, /decide …
│   └── settings.json       ← права: что ассистенту можно, что нельзя
├── 00 Входящие/            ← сюда кидаешь всё подряд
├── 01 Дневник/             ← ежедневные и недельные заметки
├── 02 Проекты/             ← дела с результатом и сроком
├── 03 Сферы/               ← здоровье, финансы, работа, отношения, развитие
├── 04 Знания/              ← справочник, конспекты, идеи
├── 05 Архив/               ← завершённое (ассистент ничего не удаляет)
├── 10 Я/                   ← ПАМЯТЬ: профиль, ценности, люди, решения, предпочтения
└── 90 Шаблоны/             ← шаблоны заметок
```

## Установка (≈10 минут)

1. **Скачай хранилище** на компьютер:
   ```bash
   git clone https://github.com/c4erepk0/AI_Obsidian.git
   ```
2. **Открой в Obsidian**: «Open folder as vault» → выбери папку `AI_Obsidian`.
3. **Установи Claude Code** (нужна подписка Claude Pro/Max или API-ключ):
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
4. **Запусти ассистента** в папке хранилища:
   ```bash
   cd AI_Obsidian
   claude
   ```
5. **Познакомься**: введи `/interview`. Ассистент задаст вопросы и заполнит `10 Я/`.
   Это самый важный шаг: чем больше он о тебе знает, тем полезнее советы.

### Работа прямо из Obsidian (по желанию)

Чтобы не переключаться в отдельный терминал, поставь сторонний плагин
(Settings → Community plugins), который встраивает терминал или Claude Code в
боковую панель, например **Terminal** или **Claudian**. Запускай в нём `claude`.

Полезные плагины для хранилища: **Tasks** (задачи со сроками), **Dataview**
(таблицы по свойствам заметок), **Calendar** (навигация по дневнику),
**Obsidian Git** (автосинхронизация с GitHub).

### С телефона

Подключи синхронизацию через **Obsidian Git** (или Obsidian Sync + git на компьютере).
Тогда ассистента можно запускать и через [claude.ai/code](https://claude.ai/code)
на этом репозитории: он прочитает заметки, внесёт изменения и запушит их,
а Obsidian на телефоне подтянет изменения.

## Команды

| Команда | Когда использовать |
|---|---|
| `/interview` | Первый запуск; потом раз в пару месяцев, чтобы обновить память. |
| `/daily` | Утром — план дня. Вечером — итоги. Можно передать мысли: `/daily устал, плохо спал`. |
| `/inbox` | Когда во «Входящих» накопилось. |
| `/weekly` | Раз в неделю, например в воскресенье. |
| `/decide <вопрос>` | `/decide менять ли работу` — разбор с вариантами и рекомендацией. |
| `/remember <факт>` | `/remember у мамы день рождения 12 марта`. |
| `/audit` | Раз в месяц: топ-3 рычага улучшения жизни + чистка хранилища. |
| `/ask <вопрос>` | `/ask что я решил про отпуск?` — ответ со ссылками на заметки. |

Можно и просто писать ассистенту обычными словами. Команды — это готовые
сценарии для частых задач.

## Распорядок, который даёт результат

1. **Каждый день** (2–5 мин): `/daily` утром, несколько строк в дневник вечером.
2. **В течение дня**: любые мысли — во `00 Входящие/` (с телефона тоже).
3. **Раз в неделю** (15 мин): `/inbox` → `/weekly`.
4. **Раз в месяц**: `/audit`.
5. **Перед важным выбором**: `/decide`.

## Настройка под себя

- Правила поведения ассистента — в [`CLAUDE.md`](CLAUDE.md). Меняй смело.
- Как ассистент общается с тобой — в `10 Я/Предпочтения ассистента.md`.
- Свои сценарии — добавляй файлы `.md` в `.claude/commands/`
  (имя файла = имя команды, `$ARGUMENTS` = текст после команды).
- Права (что можно без спроса) — в `.claude/settings.json`. По умолчанию
  ассистенту запрещено удалять файлы (`rm`) и менять настройки Obsidian.

## ⚠️ Приватность

В этом хранилище будут личные данные: здоровье, деньги, отношения.

- Держи репозиторий на GitHub **приватным**.
- Не храни здесь пароли, номера карт и коды доступа: ассистенту запрещено их записывать.
- Содержимое заметок отправляется в Claude, когда ассистент их читает.
  Учитывай это при записи очень чувствительных данных.
